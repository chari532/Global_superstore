# Global Superstore Sales Analysis

Analysis of the **Global Superstore** sales dataset (2016) using Excel. This repository stores the source data files and related work for the project.

## Project Overview

The goal of this project is to explore retail sales data and understand performance over time, such as yearly sales, profit and trends across categories and regions.

## Repository Contents

| File | Description |
|------|-------------|
| `New_global_superstore_2016.xlsx` | Global Superstore dataset (2016) |
| `New_global_superstore.xlsx` | Global Superstore dataset (updated version) |

## Dataset

The Excel files contain order-level sales records. Typical fields in this kind of dataset include:

- Order ID and order date
- Customer, segment and region
- Product category and sub-category
- Sales, quantity, discount and profit

> Open the `.xlsx` files to confirm the exact column names used in your version.

## Analysis Ideas

- Yearly and monthly sales trends
- Sales and profit by category and sub-category
- Performance by region and customer segment
- Impact of discounts on profit
- Top and bottom performing products

## Tools Used

- Microsoft Excel (data cleaning, pivot tables, charts)
- Google Sheets (charts)
- Git and GitHub (version control and hosting)

## How to Use

1. Download or clone this repository:
   ```bash
   git clone https://github.com/chari532/global_superstore.git
   ```
2. Open the `.xlsx` file in Excel or Google Sheets.
3. Explore the data using pivot tables and charts.
